# protolude

## Prérequis
- Le joueur doit avoir ramassé le panier, le sac de farine, la citrouille et le fromage pour remplir le chariot de provisions
- Si le joueur ramasse le champignon, il recommence le niveau

## Intéractions requises:
1. Ramasser le panier à l'entrée de la forêt (clique sur e)
2. Ramasser le sac de farine, la citrouille et le fromage qui sont placé dans la forêt en suivant le chemin (clique sur e)
3. Ne pas ramasser le champignon
4. Remplir le chariot (cliquer sur e)
